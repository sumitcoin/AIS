# ASHA International School

A responsive React website inspired by the Shelly school reference, with original ASHA SVG branding.

## Run

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Upload the `dist` directory to any static website host. This is a standard Vite/React project with semantic HTML and plain CSS; no hosting service is required.

## Customise

- Page content and interactions: `src/main.jsx`
- Colours, responsive layout, typography: `src/styles.css`
- Full vector logo: `public/logo.svg`
- Logo symbol / favicon: `public/logo-mark.svg`
- Illustrative stock classroom photograph: `public/learning.jpg`

School address, official contact information, fees, board affiliation, staff names, and verified admissions dates were not supplied and have not been invented. Programme descriptions are proposed content for school review. Replace the illustrative stock image with approved school photographs before public launch.

The enquiry form downloads a text file locally. It does not submit information to a server. Connect a school-approved endpoint before changing it to a submission form.
